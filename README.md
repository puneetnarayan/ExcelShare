# ExcelShare

Collaborative Excel-style web spreadsheet, V1.

## Current V1
- 5 sample worksheets
- Compact Excel-like grid
- 60 visible rows
- 12 visible columns
- Sticky column headers
- Sticky row numbers
- Cell editing
- Formula bar
- Changed-cell highlighting
- Edit history
- Undo/redo
- Freeze first row
- Text wrapping
- Sheet tabs

## Deployment
This is a static Vercel-ready app. Connect the GitHub repository to Vercel and use the repository root as the project root.
